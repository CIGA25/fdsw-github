# Desafío: Flujo de Trabajo con Git y GitHub 🚀

Este proyecto forma parte del módulo de Introducción. El objetivo principal es demostrar el dominio del flujo de trabajo colaborativo en entornos de desarrollo real, utilizando herramientas de control de versiones para la gestión de proyectos.

## 🎯 Objetivos del Desafío
* **Forking:** Realizar una bifurcación del repositorio original para trabajar en una copia propia.
* **Gestión de Commits:** Mantener un historial de cambios detallado con un mínimo de 5 commits descriptivos.
* **Control de Versiones:** Aplicar el ciclo completo de Git: Clonar, Modificar (Add), Confirmar (Commit) y Sincronizar (Push).

## 🛠️ Tecnologías Utilizadas
* **Git:** Control de versiones local para el seguimiento de cambios.
* **GitHub:** Plataforma de alojamiento para la colaboración y gestión de repositorios remotos.

## 📋 Pasos Realizados
1.  **Fork del Repositorio:** Se creó una copia del repositorio original en mi perfil personal.
2.  **Clonación Local:** Descarga del proyecto al entorno local de desarrollo.
3.  **Desarrollo Incremental:** Se realizaron modificaciones sucesivas en el código/archivos, asegurando que cada cambio significativo quedara registrado.
4.  **Historial de Commits:** Se generaron al menos 5 puntos de control con mensajes claros que describen la evolución del trabajo.
5.  **Sincronización Final:** Envío de todos los commits locales al repositorio remoto mediante `git push`.

## 📂 Estructura del Historial
El historial de este repositorio refleja una metodología de trabajo organizada, facilitando la trazabilidad de los cambios y la reversión de estados en caso de ser necesario.
